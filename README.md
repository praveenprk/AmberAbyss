# 🌌 AmberAbyss

A minimalist, high-contrast, distraction-free theme configuration for iTerm2. Built entirely by hand to escape standard harsh terminal colors and deliver a deeply rooted, retro-modern coding environment.

![iTerm2 Custom Theme](https://shields.io)

## ✨ Core Design Features

* **True Infinite Black:** The background is locked to pure `#000000` to completely eliminate screen glare.
* **Grounded Text:** Primary screen interactions and typography are rendered in a warm, comfortable Amber Gold (`#FFB300`).
* **Earthy ANSI Override:** Standard neon blues, greens, and cyans are re-mapped into cohesive shades of warm ochre, copper, rust orange, and dark gold. This keeps tools like `git status` and `tree` unified within the aesthetic.
* **Retro Heartbeat:** The cursor is tweaked into a solid, blinking rectangular block cursor for an authentic terminal feel.
* **Breathing Room:** Includes a custom vertical line spacing multiplier (1.10) to make dense blocks of code highly scannable.
* **Ultra-Minimalist Profile:** Styled to work perfectly with a hidden native macOS window title bar and borderless layout.

## 📥 How to Import This Profile

1. Download or clone the `profile.json` file from this repository.
2. Open iTerm2 and open Settings by pressing `Cmd + ,`.
3. Navigate to the **Profiles** tab at the top.
4. Look at the bottom of the left-hand profiles column and click the **Other Actions...** dropdown menu.
5. Select **Import JSON Profile...** and choose the downloaded file.
6. Select **AmberAbyss** from your profile list and click **Other Actions... -> Set as Default**.
